keystore.p12 was excluded from this review package (binary certificate file).
To run the app locally, generate a self-signed keystore:

  keytool -genkeypair -alias poc -keyalg RSA -keysize 2048 -storetype PKCS12 ^
    -keystore keystore.p12 -validity 365 -storepass changeit

Place the generated keystore.p12 in this directory (src/main/resources/).
